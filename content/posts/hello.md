This is a sample post. Create another one with:

```powershell
hugo new content posts/my-new-post.md
```

The file lands in `content/posts/`. Change `draft: true` at the top to `false`, save, and refresh the page.

## Local preview

From the site directory, run:

```powershell
hugo server
```

Then open http://localhost:1313/ .
